プライバシーポリシー

最終更新日: 2026年10月18日

1. はじめに

CalMesh（以下「本ツール」）は、複数の Google カレンダー間で予定の占有状況のみを同期する オープンソースのソフトウェアです。本ポリシーは、本ツールが Google アカウントの情報を どのように取り扱うかを説明します。

本ツールの運営者が管理するサーバーは存在しません。 本ツールは利用者自身が自分の環境にインストールして実行するソフトウェアであり、 認証情報およびカレンダーの情報が運営者に送信されることはありません。

2. アクセスする情報

本ツールは、利用者の許可にもとづき Google Calendar API を通じて以下の情報にアクセスします。

使用する権限（スコープ）

https://www.googleapis.com/auth/calendar —— カレンダーおよびその予定の参照・作成・変更・削除の権限です。 同期先に「予定あり」のブロックを作成・更新・削除するために予定の書き込み権限が必要であり、 また、ブロック専用のカレンダーを作成する機能のためにカレンダー自体への権限が必要となるため、 このスコープを使用しています。

実際に読み取る情報

  • 接続したカレンダーの一覧と、その名称・識別子・タイムゾーン
  • 指定期間内（既定では直近から3か月先まで）の予定の開始時刻・終了時刻・終日かどうか
  • 予定の公開範囲、空き時間扱いかどうか、種別（勤務場所かどうか）、自分の返信状況
  • 予定の識別子、および本ツールが付与した識別用のマーカー
  • 予定のタイトル（同期するかどうかの判定と、利用者が明示的に設定した場合の表示に使用）

予定の参加者のメールアドレス、場所、添付ファイル、会議の URL は読み取りません。

3. 利用目的

上記の情報は、利用者が接続したカレンダー間で「予定あり」のブロックを作成・更新・削除する という単一の目的にのみ使用します。広告、分析、プロファイリング、機械学習モデルの学習、 その他いかなる目的にも使用しません。

同期先のカレンダーに書き込まれる情報は、利用者が設定した固定のタイトル、開始・終了時刻、 空き時間扱いかどうか、公開範囲、および元の予定との対応関係を示す識別子のみです。 元の予定のタイトル・本文・参加者・場所は、利用者が設定で明示的にタイトルへの 差し込みを指定した場合を除き、同期先に書き込まれません。

4. 情報の保存場所

本ツールが保存するのは、以下のファイルのみです。保存先は利用者が本ツールを実行している環境 （既定では利用者の端末のホームディレクトリ内、権限 0700 のディレクトリ）です。

アクセストークン・
リフレッシュトークン		 Google への再認証なしに同期を継続するために保存します。
OAuth クライアント情報 認証に使用します。
設定 接続したカレンダーの識別子、メールアドレス、ブロックのタイトル、 同期の条件などです。
実行結果とログ 直近の同期で作成・更新・削除した件数と、処理した予定の識別子です。 予定のタイトルや本文は含みません。

利用者が GitHub Actions 等で定期実行する構成を選んだ場合、これらの情報は利用者自身が 管理するリポジトリのシークレットに暗号化されて保存されます。いずれの場合も、 保存先は利用者の管理下にあり、運営者はアクセスできません。

カレンダーから読み取った予定の情報が、上記以外の場所に蓄積されることはありません。 予定の情報は実行中にメモリ上で処理され、実行終了とともに破棄されます。

5. 第三者への提供

本ツールは、取得した情報をいかなる第三者にも提供・販売・共有しません。 通信先は Google の API エンドポイントのみです。 解析ツール、広告ネットワーク、外部のログ収集サービスへの送信は一切行いません。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から取得した情報の使用および他アプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （Limited Use の要件を含む）に準拠します。

具体的に、本ツールは Google ユーザーデータを次のように取り扱います。

  • 利用者に対して本ツールの機能を提供する目的にのみ使用します。
  • 第三者への転送は行いません。
  • 広告目的での使用は行いません。
  • 人間による読み取りは行いません。運営者が利用者のデータを閲覧する手段はありません。

7. 権限の取り消しと削除

利用者はいつでも次の方法でアクセス権を取り消し、保存された情報を削除できます。

  1. Google アカウントの「サードパーティ製アプリとサービス」 から本ツールのアクセス権を削除する。これにより保存済みのトークンは無効になります。
  2. 本ツールの設定ディレクトリ（既定では ~/.google-calendar-sync）を削除する。 これによりトークンと設定はすべて消えます。
  3. 定期実行を設定していた場合は、本ツールの uninstall-cron コマンドで解除する。 GitHub Actions を使用していた場合は、リポジトリのシークレットを削除する。

すでに同期先のカレンダーに作成されたブロックは、利用者のカレンダー上の予定として残ります。 これらは通常の予定と同様に、利用者自身が削除できます。

8. 本サイトについて

本サイト（本ポリシーを掲載しているウェブサイト）は静的なページのみで構成されており、 クッキーを使用せず、アクセス解析も行っていません。 ただし、ホスティング事業者である Google（Firebase Hosting）において、 配信に伴うアクセスログ（IP アドレス、リクエスト日時、ユーザーエージェント等）が 記録される場合があります。

9. 安全管理

本ツールは、認証情報を権限 0700 のディレクトリ内に、所有者のみが読み書きできる 権限 0600 のファイルとして保存します。ソースコードは全文が公開されており、 情報の取り扱いは誰でも検証できます。

一方で、保存先の環境そのものの安全管理（端末のロック、ディスク暗号化、 リポジトリのアクセス管理）は利用者の責任となります。

10. 子どもの利用

本ツールは13歳未満の方の利用を想定していません。

11. 本ポリシーの変更

本ポリシーを変更する場合は、本ページを更新し、最終更新日を改めます。 取り扱いに重要な変更が生じる場合は、変更内容を本ページに明示します。
