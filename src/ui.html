gcal-sync

複数の Google カレンダーを双方向に同期し、予定の「時間枠」だけを伏せ字で埋めます。

1認証方式

どちらでも同期の動作は同じです。迷ったらサービスアカウントを選んでください。

2サービスアカウントの鍵

scripts/setup-gcp.sh を実行すると、プロジェクト作成から鍵の発行まで一度に済みます。 出力された JSON 鍵のパスを入力してください。

2OAuth クライアント

Google Cloud で「デスクトップ アプリ」の OAuth クライアントを作成し、ID とシークレットを貼り付けてください。 リダイレクト URI は です。

3Google アカウント

4同期するカレンダー

2つ以上追加すると、全対全（双方向）で同期されます。

ID名前所有同期元ミラー先

カレンダー ID は Google カレンダーの「設定と共有」→「カレンダーの統合」で確認できます。 メインカレンダーならメールアドレスそのもの、サブカレンダーなら ...@group.calendar.google.com 形式です。

ミラー先は、そのアカウントで作ったサブカレンダーを同じく共有しておくのが推奨です （一括非表示とリセットができます）。同期元と同じ ID を入れると primary 直書き相当になります。

5埋め込む文言

行が送信元、列が送信先です。「行のカレンダーの予定が、列のカレンダーにどう表示されるか」を入力します。 空欄にすると既定文言を使います。{summary} {start} {end} {durationMinutes} {calendarName} が使えます。
